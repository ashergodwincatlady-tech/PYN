# PYN v3

This version applies the product feedback from the connected **PYN - Employee** Google Doc.

## What changed

- Home stays project-first.
- **Continue learning** opens the actual lesson.
- Learn is reorganized as one **PYN Fundamentals** section with Duolingo-inspired units and a learning path, without copying Duolingo characters.
- Lessons are completed only after passing their tiny exam.
- Every project now shows readable Python reference code to every user, regardless of level.
- Every project has a **Project Check**. There is no direct “complete” button.
- A **Use VS Code to practice!** link points to the official VS Code download page.
- Users can create their own Python project cards and save code locally.
- Fake people, fake activity, and fake friend requests were removed. Real members are expected to come from a future backend/database.
- The avatar editor now uses category tabs and larger option tiles, inspired by the interaction style of an avatar creator.
- Unlockables are renamed **PYN Accessories**, with more items available through lesson/project rewards.
- Users can choose their preferred PYN accent colour.

## Run locally

From the folder containing `index.html`:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Important

This is still a browser-only MVP. Real shared accounts, real online users, friend requests between devices, moderation, parental controls, and video upload/storage require a backend and database.
